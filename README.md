# Habitat Studio Website

## Project Description
Habitat Studio is a modern architectural and interior design website built to showcase projects, services, and allow clients to submit project inquiries through a contact form.

The website includes:
1. A responsive homepage
2. Hero section with featured visuals
3. Services section
4. Contact form
5. Project submissions page


## Technologies Used
1. HTML5
2. CSS3
3. JavaScript (Vanilla JS) 
4. LocalStorage 


## Features
1. Responsive design
2. Contact/project submission form
3. Form validation
4. Success alert notifications
5. Save submitted projects locally
6. View submitted projects on (submissions.html)

## How to Run the Project
1. Download or clone the project files.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation is required.



## Form Functionality
The contact form:
1. Validates empty fields
2. Saves submissions using LocalStorage
3. Displays a success alert after submission

## Known Bugs
1. Data is stored only in the browser using LocalStorage.
2. Submitted projects disappear if browser storage is cleared.
3. No backend/database integration yet.
